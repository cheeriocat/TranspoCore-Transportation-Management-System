# TranspoCore

TranspoCore is a Java-based desktop application designed for managing transportation logistics. It includes features such as driver management, shipment tracking, schedule planning, and report generation.

## 📦 Project Structure

```
Oop_Project/
└── TranspoCore/
    ├── pom.xml
    ├── src/
    │   └── main/
    │       └── java/
    │           ├── com/sliit/transpocore/
    │           ├── dao/
    │           ├── gui/
    │           ├── Dbconnection/
    │
    └── Database.txt
```

## ✨ Features

- 📋 **Driver Management** — Add, update, and assign drivers to shipments.
- 🚚 **Shipment Scheduling** — Manage delivery and shipment plans.
- 🧾 **Report Generation** — Automatically generate and email delivery reports.
- 💻 **GUI Interface** — Built using Swing/AWT for a user-friendly experience.
- 💾 **Database Interaction** — Modular DAO classes for database operations.

## 🛠️ Tech Stack

- **Java 8+**
- **Maven** (Build tool)
- **Swing/AWT** (GUI)
- **JDBC** (Database connectivity)
- **JavaMail API** (Email utility)

## 🚀 Getting Started

1. **Clone the repository**

```bash
git clone https://github.com/yourusername/Syntax-Squad.git
cd Syntax-Squad/Oop_Project/TranspoCore
```

2. **Build the project with Maven**

```bash
mvn clean install
```

3. **Run the application**

Run the `TranspoCore.java` file located at:
```
src/main/java/com/sliit/transpocore/TranspoCore.java
```
